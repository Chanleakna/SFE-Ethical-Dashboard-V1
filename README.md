# SFE KPI Dashboard

Live dashboard for Abbott Cambodia Ethical division.

## Setup

1. Open `src/App.jsx`
2. Find the line: `const API_URL = "PASTE_YOUR_APPS_SCRIPT_URL_HERE";`
3. Replace with your Apps Script Web App URL (ends in `/exec`)
4. Commit and push to GitHub
5. Vercel auto-deploys on every push

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
